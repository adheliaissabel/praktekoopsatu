# Praktek OOP Satu 🚀

Repositori ini dibuat untuk mendokumentasikan tugas, latihan, atau proyek praktikum pertama pada mata kuliah **Pemrograman Berorientasi Objek (Object-Oriented Programming - OOP)**. 

Repositori ini menjadi fondasi awal sebelum melanjutkan ke [Praktek OOP Dua](https://github.com/adheliaissabel/praktekoopdua).

## 📌 Deskripsi Proyek
Proyek ini berfokus pada pengenalan dan implementasi konsep-konsep dasar dari pemrograman berorientasi objek. Di dalam repositori ini, terdapat latihan awal mengenai bagaimana membuat struktur kode yang modular, efisien, dan terorganisir menggunakan paradigma OOP.

## 💻 Konsep OOP Dasar yang Diimplementasikan
Proyek ini menerapkan konsep-konsep fundamental OOP, antara lain:
*   **Class & Object (Kelas & Objek):** Membuat cetak biru (*blueprint*) berupa kelas dan melakukan instansiasi menjadi objek di dalam program.
*   **Attributes & Methods (Atribut & Metode):** Mendefinisikan variabel (state) dan fungsi/perilaku (behavior) yang melekat pada suatu objek.
*   **Constructor (Konstruktor):** Menggunakan metode khusus untuk menginisialisasi nilai awal saat objek pertama kali dibuat.
*   **Basic Encapsulation:** Pengenalan awal mengenai pembatasan akses data menggunakan modifier dasar.
